# Wild Hausa — Premium Antigravity Agent Brief

## Read This First

This is **not** a generic vibe-coding template.

Wild Hausa must feel like a distinctive African eco-tourism, conservation, wildlife media, and adventure brand. The interface should look custom-made for **Wild Hausa**, not like a copied SaaS dashboard or ordinary tourism website.

The web app should express:

- Northern Nigerian / Sahel-inspired landscapes
- Wildlife storytelling
- Conservation education
- Safari adventure
- Premium outdoor experiences
- Cinematic documentary production
- Trust, safety, and professionalism

Every agent must prioritize **brand uniqueness, visual storytelling, and cultural-natural identity** over generic layouts.

---

## Project Identity

**Project Name:** Wild Hausa Web Platform  
**Tagline:** Bringing People Closer to Nature  
**Brand Character:** Wild, grounded, cinematic, educational, adventurous, African, premium, conservation-led

Wild Hausa operates across:

1. Digital Media & Nature Filmmaking
2. Eco-Tourism & Safaris
3. Adventure Parks & Outdoor Recreation
4. Zoological & Conservation Facilities
5. Conservation Education

The app should feel like a hybrid of:

- A safari booking platform
- A nature documentary studio
- A conservation education hub
- An adventure park access portal
- A premium brand website

## Non-Generic Design Rule

Do **not** generate a basic landing page with random cards, stock gradients, and generic section blocks.

Avoid:

- Generic SaaS hero sections
- Plain white dashboards with blue buttons
- Random travel website templates
- Overused glassmorphism
- Generic AI-generated icons without meaning
- Generic lorem ipsum content
- Unrelated mountain or beach visuals
- Copy-paste component library appearance
- Overly corporate fintech-style UI

Instead, create a custom design system based on the Wild Hausa logo, wildlife silhouettes, Sahel earth tones, circular safari motifs, documentary framing, and conservation storytelling.

2. **Sunset Disk**
   - Use orange sun shapes behind hero text or image blocks.
   - Create subtle sunset overlays on cards.

3. **Wildlife Silhouettes**
   - Use subtle animal silhouettes as background ornaments.
   - Use silhouette dividers between major sections.

4. **Acacia / Dry Tree Motif**

5. **Documentary Frame Motif**
   - Use thin rectangular frame overlays on media cards.
   - Use small “REC”, “Field Note”, or “Expedition Log” labels where appropriate.
   - Make the media section feel like a nature documentary archive.

### Map Data Model

Add Supabase table:

```sql
create table map_locations (
  id uuid primary key default gen_random_uuid(),
  title text not null,
  slug text unique not null,
  category text not null,
  description text,
  location_name text,
  state_region text,
  latitude numeric not null,
  longitude numeric not null,
  image_url text,
  best_for text,
  estimated_duration text,
  travel_note text,
  related_safari_id uuid references safari_packages(id) on delete set null,
  related_media_id uuid references media_items(id) on delete set null,
  related_activity_id uuid references activities(id) on delete set null,
  is_featured boolean default false,
  is_active boolean default true,
  created_at timestamp with time zone default now(),
  updated_at timestamp with time zone default now()
);
```

Optional route tables:

```sql
create table expedition_routes (
  id uuid primary key default gen_random_uuid(),
  title text not null,
  slug text unique not null,
  description text,
  start_location_id uuid references map_locations(id) on delete set null,
  end_location_id uuid references map_locations(id) on delete set null,
  duration text,
  group_type text,
  highlights text,
  related_safari_id uuid references safari_packages(id) on delete set null,
  is_active boolean default true,
  created_at timestamp with time zone default now(),
  updated_at timestamp with time zone default now()
);

create table expedition_route_stops (
  id uuid primary key default gen_random_uuid(),
  route_id uuid references expedition_routes(id) on delete cascade,
  location_id uuid references map_locations(id) on delete cascade,
  stop_order integer not null,
  stop_note text,
  created_at timestamp with time zone default now()
);
```

### Mobile Map Experience

- Full-width map
- Sticky filter bar or horizontal scroll filters
- Bottom-sheet marker details
- Large tap targets
- No tiny default popups as the only interaction
- CTA buttons visible without excessive scrolling

### Map Performance and Safety

- Lazy-load the map component to avoid slowing the homepage.
- Avoid rendering too many markers at once without clustering.
- Use marker clustering later if many map points exist.
- Validate coordinates before saving.
- Do not expose secret map API keys in client code.
- If using Mapbox, use public token safely and restrict usage where possible.

## Quality Standard

The app is not complete if it looks like a generic generated template.

Before marking complete, verify:

- The design clearly feels like Wild Hausa.
- Logo colors and motifs are reflected across the UI.
- The home page has a custom expedition story flow.
- Components are reusable but visually distinctive.
- The admin dashboard is branded.
- Cards, buttons, and labels use custom Wild Hausa language.
- Mobile view maintains the premium safari feel.
- Forms are polished and easy to use.
